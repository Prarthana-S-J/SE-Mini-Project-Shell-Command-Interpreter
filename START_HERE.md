# START HERE - base project

This is the starting point for the Simple Shell mini project (Part-2 sprints).

1. `make && ./mysh` - builds; the shell only prints a banner because nothing is implemented yet.
2. `bash tests/run_tests.sh` - runs; almost every test shows `SKIP (not implemented yet)`.
3. Read `stories/README.md` - it explains how each backlog story is added through a patch and a pull request, in which order, and which tests each story must pass.
4. Backlog, story points and sprint plan: `docs/SPRINT_PLAN.md`; GitHub setup: `backlog/README.md`.

The finished shell (all stories applied) is in the other folder, `simple-shell/`, for reference.
